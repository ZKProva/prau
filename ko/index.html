iPhone용 오프라인 음성 번역기

내 언어로 말하세요.
상대의 언어로 전해집니다.

Prau는 19개 언어를 인식하고 번역하고 소리 내어 읽습니다 — 전부 iPhone 안에서. 인터넷도, 계정도, 서버도 없습니다. 당신이 말한 어떤 것도 어디로도 전송되지 않습니다.

Prau의 실제 화면입니다 — 연출은 없습니다.

비행기 모드 켜짐 — 문장이 iPhone 안에서만 번역되고 재생됩니다. 컷 없이 한 번에 찍은 영상입니다.

작동 방식

세 단계면 끝 — 그다음은 어디서든 그냥 됩니다.

  1. 언어 쌍 선택

    상단의 언어 버튼을 탭하세요. 처음에는 iOS가 언어 팩 다운로드를 제안합니다 — 확인하면, 이후 번역에 네트워크가 전혀 필요 없습니다.

  2. 마이크를 탭하고 말하기

    Prau가 기기에서 말을 인식해 번역하고 소리 내어 읽어 줍니다. 상대가 대답하면, 그 답을 자기 언어로 듣게 됩니다.

  3. 대화 보관

    모든 대화가 자동으로 저장됩니다. 검색하고, 다시 열고, TXT나 PDF로 내보내고, 공유하세요. 이 기능은 언제나 무료입니다.

글로 읽지 말고, 눈으로 확인하세요

아래 모든 화면은 오늘 iPhone에서 돌아가는 Prau 1.0 그대로입니다.

🎧

이어폰으로 듣는 번역

AirPods 등 아무 이어폰이나 연결하세요. 내 언어로 된 번역은 귓가에서 조용히 재생되고, 상대는 스피커로 자기 언어를 듣습니다.

👥

마주 보기 모드

휴대폰을 두 사람 사이에 놓으세요. 화면이 둘로 나뉘어 각자 바른 방향, 자기 언어로 보이고, 번갈아 말하면 됩니다. 호텔 프런트, 약국, 택시, 상점을 위해 만들었습니다.

🕘

상대별로 하나의 대화 — 음성·사진·PDF를 한곳에

모든 대화가 iPhone에 저장됩니다. 대화를 오른쪽으로 쓸어 이름을 바꾸세요 — ‘리스본 호텔’, ‘집주인’. 열어서 ‘이 대화 이어가기’를 탭하면 새 음성·사진·PDF 페이지가 같은 스레드에 쌓입니다. 상대 한 명이면 기록 하나, 요약 하나, 내보내기 하나. 전체 검색이 되고, 어떤 대화든 TXT/PDF로 내보낼 수 있습니다. 카드에서 길게 눌러 단어나 문구를 선택·복사하세요. 번역 기록·검색·내보내기·복사에는 구독이 필요 없습니다 — 지금도, 앞으로도.

✨

iPhone에서 작성되는 요약

Apple Intelligence를 지원하는 iPhone이라면 대화 전체의 짧은 요약을 받아 보세요 — 핵심만 몇 줄로, 기기에서 작성되며 어디로도 전송되지 않습니다.

📷

사진과 PDF

메뉴판·표지판·문서에 카메라를 대거나 PDF를 불러오세요. 텍스트가 기기에서 인식·번역되어 읽기 좋은 문단으로 정리되고, PDF로 내보낼 수 있습니다.

🎙

오프라인 음성 대화

음성 인식·번역·음성 출력이 모두 iPhone에서 실행됩니다. 비행기에서, 산에서, 유심 없는 해외에서, 신호가 약한 어디서든 사용할 수 있습니다.

⌨️

텍스트 입력과 말하기 속도

조용해야 할 때는 말하는 대신 입력하세요. 상대가 따라오기 어려우면 번역 음성을 느리게. 시스템에 여러 음성이 있으면 목소리도 고를 수 있습니다.

여행 전에 한 번만 설정

두 가지는 Prau가 아니라 iOS 안에 있습니다. 집에서 Wi-Fi로 끝내 두면 — 이후에는 네트워크가 전혀 없어도 모든 것이 동작합니다.

  1. 번역용 언어 팩

    Prau를 열고 언어 쌍을 고르세요. iOS가 ‘필수 다운로드’ 시트를 띄웁니다 — 각 언어 옆 화살표를 탭하세요. 언어당 약 50–100MB, 한 번이면 됩니다. 나중에 Prau → 설정 → 언어에서도 추가할 수 있습니다.

  2. 내 목소리를 위한 오프라인 받아쓰기

    iPhone 설정 → 일반 → 키보드 → 받아쓰기 언어. 말할 언어를 모두 추가하세요. 목록에 없는 언어는 키보드를 한 번 추가하면 됩니다(키보드 → 키보드 → 새로운 키보드 추가) — 받아쓰기가 자동으로 따라옵니다. 모델은 iOS가 백그라운드에서 내려받으며 보통 하루 안, Wi-Fi·충전 중일 때 가장 빠릅니다. Prau → 설정 → 언어에서 초록 마이크가 보이면 준비 완료입니다.

  3. 이어폰 — 선택 사항

    AirPods 등 아무 이어폰이나 연결하고 Prau 설정에서 ‘내 언어’를 고르세요. 내 번역은 귓가에서 조용히, 상대 번역은 폰 스피커로 나옵니다.

텍스트·사진 번역에는 받아쓰기가 전혀 필요 없습니다 — 언어 팩만 들어 있으면 바로 됩니다.

19개 언어, 완전 오프라인

영어, 프랑스어, 독일어, 스페인어, 이탈리아어, 포르투갈어, 네덜란드어, 폴란드어, 우크라이나어, 러시아어, 튀르키예어, 아랍어, 중국어(간체·번체), 일본어, 한국어, 인도네시아어, 태국어, 베트남어. 이 중 어떤 조합이든.

음성 입력은 iOS가 해당 언어의 오프라인 받아쓰기 모델을 설치한 언어에서 동작합니다 — 언어 화면의 초록 마이크가 준비된 언어를 표시합니다. 텍스트·사진 번역은 어떤 경우든 19개 언어 모두 지원합니다.

프라이버시는 설정이 아니라 설계입니다

대부분의 번역기는 당신의 음성을 서버로 보냅니다. Prau에는 서버 자체가 없습니다.

iPhone에 남는 것

  • 말하고 들은 모든 것
  • 입력한 모든 것
  • 사진·PDF와 인식된 텍스트
  • 대화 기록과 검색
  • 대화 요약(Apple Intelligence, 온디바이스)

iPhone을 떠나는 것

  • 구독 상태 — 익명 ID와 App Store 영수증뿐입니다. RevenueCat을 통해 확인되어 앱이 Pro 활성 여부를 알게 됩니다. 그 외에는 아무것도 없습니다.
  • 계정 없음, 로그인 없음.
  • 분석 없음, 광고 없음, 추적 SDK 없음.
  • 자체 서버 없음 — 애초에 업로드할 곳이 없습니다.
  • Apple의 온디바이스 프레임워크만 사용: Speech, Translation, Vision, AVFoundation.
  • 대화를 하나든 전부든 언제든 삭제하세요. 앱을 지우면 기록도 함께 사라집니다.

지원

특정 언어의 마이크에 사선이 그어져 있어요

음성 입력에는 iOS가 그 언어용으로 설치하는 오프라인 받아쓰기 모델이 필요합니다. 설정 → 일반 → 키보드 → 받아쓰기 언어를 열어 보세요. 언어가 목록에 있다면 iOS가 백그라운드에서 모델을 내려받는 중입니다(보통 하루 안, Wi-Fi 연결·충전 중일 때 가장 빠름). 목록에 없다면 그 언어의 키보드를 한 번 추가하세요 — 받아쓰기는 자동으로 켜집니다. 그때까지도 텍스트·사진 번역은 전부 사용할 수 있습니다.

시스템 ‘필수 다운로드’ 시트가 떠요

Apple 번역 프레임워크가 언어 팩을 요청하는 것입니다. 각 언어 옆 화살표를 탭하세요. 탭하기 전에는 다운로드가 시작되지 않습니다. 완료되면 번역은 영구히 오프라인으로 동작합니다.

번역이 느리거나 번역기가 반응하지 않아요

iOS 쪽 현상으로, 보통 언어 팩 설치 직후에 나타나며 1분 안에 사라집니다. 반복되면 iPhone을 재시동하세요.

결제했는데 Pro가 활성화되지 않아요

결제 화면이나 설정에서 ‘구매 복원’을 탭하세요. 구매는 Apple 계정에 묶여 있어 어떤 iPhone에서도 복원됩니다. 그래도 안 되면 App Store 영수증과 함께 메일 주세요.

구독은 어떻게 해지하나요?

iPhone 설정 → 내 이름 → 구독 → Prau. 해지해도 결제한 기간이 끝날 때까지 Pro가 유지됩니다.

어떤 iPhone을 지원하나요?

iOS 18 이상이 구동되는 모든 iPhone. 대화 요약에는 추가로 Apple Intelligence(iPhone 15 Pro 이상)와 지원되는 시스템 언어가 필요합니다.
