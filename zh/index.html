工作原理

三步设置，然后随处可用。

  1. 选择语言对

    点按顶部的语言按钮。首次使用时 iOS 会提示下载语言包——确认后，翻译从此不再需要网络。

  2. 点按麦克风开始说话

    Prau 在设备上识别你的话，翻译并朗读出来。对方回答后，会听到自己语言的回复。

  3. 保留对话

    每段对话都会自动保存。可搜索、可重新打开、可导出为 TXT 或 PDF 并分享。这部分永久免费。

出行前，一次设置好

有两件事在 iOS 里，而不在 Prau 里。在家连 Wi-Fi 完成——之后一切无需任何网络。

  1. 翻译语言包

    打开 Prau 选择语言对。iOS 会显示“所需下载项”——点按每种语言旁的箭头。每种语言约 50–100 MB，只需一次。之后也可在 Prau → 设置 → 语言中添加。

  2. 为你的语音准备离线听写

    iPhone 设置 → 通用 → 键盘 → 听写语言。添加你要说的每种语言。若列表中没有某种语言，先添加一次它的键盘（键盘 → 键盘 → 添加新键盘）——听写会自动跟上。iOS 在后台下载模型，通常一天内完成，连 Wi-Fi 并充电时最快。在 Prau → 设置 → 语言中，绿色麦克风表示该语言已就绪。

  3. 耳机——可选

    连接 AirPods 或任意耳机，在 Prau 设置中选择“我的语言”。你的译文轻声在耳边播放；对方从手机扬声器听到他的。

文字和照片翻译完全不需要听写——语言包装好即可使用。

支持

某个语言的麦克风带删除线

语音输入需要 iOS 为该语言安装的离线听写模型。打开设置 → 通用 → 键盘 → 听写语言：如果语言已在列表中，iOS 正在后台下载模型（通常一天内完成，连接 Wi-Fi 并充电时最快）。如果不在列表中，添加一次该语言的键盘——听写会自动开启。在此之前，文字和照片翻译完全可用。

出现系统“所需下载项”弹窗

这是 Apple 翻译框架在请求语言包。点按每种语言旁的箭头；不点按不会开始下载。完成后，翻译永久离线可用。

翻译很慢或翻译器没有反应

这是 iOS 侧的现象，通常出现在语言包刚安装后，一分钟内会恢复。若反复出现，请重启 iPhone。
